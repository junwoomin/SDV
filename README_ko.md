# SDV Studio

![SDV Studio 한국어 대시보드](docs/images/dashboard-ko.png)

*데이터 수집, 모델 학습, 실험 관리를 위한 메인 대시보드입니다.*

**SDV Studio는 CARLA 기반 자율주행 실험을 위한 연구용 프로토타입입니다.** 시뮬레이션 설정, 센서 데이터 수집, 데이터셋 준비, 인지 모델 학습, 결과 확인을 하나의 로컬 웹 작업 공간에서 진행합니다. 우측 상단 **KO / EN**에서 한국어와 영어를 선택할 수 있습니다.

[English](README.md) · [사진으로 보는 사용 안내](docs/USER_GUIDE_KO.md) · [환경 준비](docs/SETUP_KO.md) · [저장소 구조](docs/REPOSITORY_LAYOUT.md)

## 주요 기능

| 영역 | 설명 |
| --- | --- |
| 시뮬레이션 | CARLA, Town, 교통량, 주행 모드와 엔진 진단을 설정하고 호환 Roach 정책을 연결합니다. |
| 센서·데이터 수집 | 카메라·LiDAR·IMU를 구성하고 센서 미리보기, 프레임 정렬 수집, 저장 진행률 확인을 제공합니다. |
| 시퀀스 분석 | 같은 프레임의 RGB·Segmentation·Depth·객체 주석·BEV를 함께 재생합니다. |
| 데이터셋 준비 | 장면 단위로 TRAIN·VAL을 나누고 수집 당시 보정 정보와 함께 데이터를 복사합니다. |
| 인지 모델 학습 | 이미지 Encoder, 이미지·BEV Decoder, 태스크, 손실 함수와 학습 파라미터를 선택합니다. |
| 실험 관리 | 작업 대기열, Epoch 경계 일시정지·재개, 지표·체크포인트 확인, 저장 예측 탐색을 제공합니다. |

## 실행

Linux와 Python 3.7 이상 환경에서 실행합니다.

```bash
./start.sh
```

[http://127.0.0.1:8765](http://127.0.0.1:8765)를 엽니다. 실행 스크립트는 별도 웹 가상환경을 준비하고 의존성을 설치합니다. **시스템 설정**에서 수집·학습에 사용할 연구 Python과 CARLA 0.9.15 설치 경로를 지정합니다. 필요한 환경과 자산은 [환경 준비](docs/SETUP_KO.md)에 설명되어 있습니다.

## 사용 흐름

1. **시스템 설정:** 연구 Python, CARLA 설치 위치, 저장 경로를 정하고 진단합니다.
2. **시뮬레이션·센서 구성:** Town, 주행 모드, 센서 출력을 정하고 CARLA 실행과 준비 상태를 확인합니다.
3. **데이터 수집:** 샘플을 수집하고 저장 미리보기, 샘플 수, 작업 로그를 확인합니다.
4. **시퀀스·데이터셋:** 데이터를 재생하고 서로 다른 장면을 TRAIN·VAL로 나눠 데이터셋을 준비합니다.
5. **모델 학습:** 모델, 태스크, 손실 함수, 학습 파라미터를 선택하고 준비 검사 후 실행하거나 대기열에 추가합니다.
6. **모니터링·실험 결과:** 지표, 체크포인트, 저장된 입력·정답·예측 이미지를 확인합니다.

## 개발 상태와 실행 조건

연구 실험을 구성하고 결과를 살펴보는 프로토타입 단계입니다. 주행 정책의 환경 간 이전, BEV 카메라 기하 정합, 장시간 실행 안정성, 모델 수렴은 추가 평가 대상입니다. 화면 사진은 인터페이스를 설명하며, 모델 성능은 독립적인 검증 데이터셋으로 평가해야 합니다.

CARLA, 일치하는 Python API, 연구용 PyTorch·CUDA 의존성, 데이터셋과 보정 정보는 별도로 준비합니다. Global BEV 지도에는 일치하는 catalog가 필요하며 Roach 수집에는 호환 체크포인트가 추가로 필요합니다. 각 작업의 준비 검사에서 필요한 자산을 확인합니다. 지도와 체크포인트의 재배포 권한은 코드 라이선스와 별도입니다.
